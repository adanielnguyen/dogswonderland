# Dogs Wonderland — dogswonderlandkyneton.com

Static React + Vite site, hosted on Netlify. Migrated off Manus.

- `pnpm install` then `pnpm dev` to run locally, `pnpm build` outputs to `dist/`.
- Images live in `client/public/images/`.
- Booking enquiries are captured by **Netlify Forms** (form name `booking`).
  Set up the email notification in Netlify: Site configuration → Forms → Form notifications → Email → maifrances@gmail.com.
